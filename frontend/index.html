Distribution of Book Ratings (0 to 10)

      _id: "$Book-Rating",

FIGURE 2

Most Frequently Rated Books ($lookup Join)

Groups ratings by ISBN, computes explicit rating mean, and executes a $lookup join with the books collection for metadata.

MongoDB Pipeline ($lookup join) 
db.ratings.aggregate([
  {
    $group: {
      _id: "$ISBN",
      totalRatings: { $sum: 1 },
      explicitRatings: {
        $sum: { $cond: [{ $gt: ["$Book-Rating", 0] }, 1, 0] }
      },
      sumScore: {
        $sum: { $cond: [{ $gt: ["$Book-Rating", 0] }, "$Book-Rating", 0] }
      }
    }
  },
  { $match: { totalRatings: { $gte: 3 } } },
  {
    $lookup: {
      from: "books",
      localField: "_id",
      foreignField: "ISBN",
      as: "book"
    }
  },
  { $unwind: "$book" },
  {
    $project: {
      title: "$book.Book-Title",
      author: "$book.Book-Author",
      totalRatings: 1,
      meanPositiveRating: {
        $round: [{ $divide: ["$sumScore", "$explicitRatings"] }, 2]
      }
    }
  },
  { $sort: { totalRatings: -1 } },
  { $limit: 7 }
])

FIGURE 3

Authors with Largest Catalogue Representation

Aggregates document counts grouped by Book-Author in the books collection.

MongoDB Query (Collection: books) 
db.books.aggregate([
  {
    $match: {
      "Book-Author": {
        $nin: [null, "", "Unknown Author", "nan"]
      }
    }
  },
  {
    $group: {
      _id: "$Book-Author",
      bookCount: { $sum: 1 }
    }
  },
  { $sort: { bookCount: -1 } },
  { $limit: 8 }
])

FIGURE 4

Book Catalogue by Publication-Year Band

Validates and categorizes publication years into cohorts (`≤1900` to `2011–2026`) via a $switch stage.

MongoDB Query (Collection: books) 
db.books.aggregate([
  {
    $match: {
      "Year-Of-Publication": { $gte: 1450, $lte: 2026 }
    }
  },
  {
    $project: {
      yearBand: {
        $switch: {
          branches: [
            { case: { $lte: ["$Year-Of-Publication", 1900] }, then: "≤1900" },
            { case: { $and: [{ $gte: ["$Year-Of-Publication", 1901] }, { $lte: ["$Year-Of-Publication", 1950] }] }, then: "1901–1950" },
            { case: { $and: [{ $gte: ["$Year-Of-Publication", 1951] }, { $lte: ["$Year-Of-Publication", 1980] }] }, then: "1951–1980" },
            { case: { $and: [{ $gte: ["$Year-Of-Publication", 1981] }, { $lte: ["$Year-Of-Publication", 1990] }] }, then: "1981–1990" },
            { case: { $and: [{ $gte: ["$Year-Of-Publication", 1991] }, { $lte: ["$Year-Of-Publication", 2000] }] }, then: "1991–2000" },
            { case: { $and: [{ $gte: ["$Year-Of-Publication", 2001] }, { $lte: ["$Year-Of-Publication", 2010] }] }, then: "2001–2010" },
            { case: { $gte: ["$Year-Of-Publication", 2011] }, then: "2011–2026" }
          ],
          default: "Other"
        }
      }
    }
  },
  { $group: { _id: "$yearBand", count: { $sum: 1 } } }
])

FIGURE 5

User Age Data Availability (Present vs. Missing)

Demonstrating the observed data gap where Age is absent in ~39.7% of reader records.

MongoDB Query (Collection: users) 
db.users.aggregate([
  {
    $group: {
      _id: {
        $cond: [
          { $ne: ["$Age", null] },
          "Age Present",
          "Age Missing"
        ]
      },
      count: { $sum: 1 }
    }
  }
])
